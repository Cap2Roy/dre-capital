Authentication

All /api/ endpoints (except webhooks) require an authenticated session cookie (dre_session), set by POST /api/auth/login.

Write endpoints (create / update / delete) marked admin in the router require an admin-role user. Read endpoints require any authenticated user.

Public webhooks (no auth): POST /api/calls/twilio-status (Twilio call-status callback), POST /api/messages/inbound (Twilio SMS inbound).
